The Java 21 image builds and starts Generational ZGC locally. Its performance
is unmeasured. Flink calls Java 21 experimental, so its trials use `tuned`.
The next six-hour payload plan prioritizes recovery, then three bilateral A/A
repetitions against the original width-32 baseline. It refuses a smaller budget.

GC workers at width 32, a 256-MiB network cap, and specific/custom Avro are explicit
mechanism probes. Reduced-width large batches and the 25,000-row width-16 case
remain concrete deferred cells pending issue #78. Four TaskManagers have no open
proposal: #76 was closed, so that topology would need a fresh contract PR.
None is represented as executed or ranked by an unreplicated point estimate.

The proposed immediate default promotion is deferred: a contract-compliant
configuration still needs recovery and credible confirmation. The screening
win does not turn a false acceptance verdict into a pass. The first follow-up
also showed a candidate A/A spread over the threshold, so its quiet behavior
cannot be presumed from the first session.
